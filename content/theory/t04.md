## 학습 목표

- 이펙터 중심 위치 $P = (x, y, z)$에서 모터각 $θᵢ$를 구하는 닫힌 해를 **팔 하나씩 독립적으로** 유도할 수 있습니다.
- 유도 과정을 기하학적으로(구 ∩ 원 → 팔 평면의 두 원의 교점) 설명하고, 두 해 중 "팔꿈치 바깥" 해를 고르는 기준을 말할 수 있습니다.
- $|K| > ρ$일 때 해가 없다(도달 불가)는 조건의 의미를 설명할 수 있습니다.
- IK를 Python으로 처음부터 구현하고 `deltarobot.kinematics.ik`와 결과를 비교할 수 있습니다.
- "팔이 닿는다"와 "로봇이 갈 수 있다"(관절·볼조인트·팔꿈치 한계)의 차이를 코드로 확인할 수 있습니다.

## 문제 정의

주어진 것: 설계 파라미터 R, r, L, l과 이펙터 중심 $P = (x, y, z)$ (베이스 좌표, m).
구할 것: 모터각 $(θ₁, θ₂, θ₃)$ (rad, 아래로 +).

델타 IK의 핵심 관찰은 **팔 세 개가 서로 독립**이라는 것입니다. 이펙터가 회전하지 않으므로(T02) P만 알면 팔 i의 볼조인트 위치
$Bᵢ = P + r·uᵢ$가 바로 정해지고, 팔 i의 모터각 θᵢ는 **Bᵢ와 팔 i의 치수만으로** 결정됩니다. 그래서 같은 계산을 φ만 바꿔 세 번 하면 됩니다.

## 유도

### 1단계 — 팔 좌표계로 회전

팔 i가 x′축 위에 오도록 z축 둘레로 −φᵢ만큼 돌립니다(T03).

```text
x′ =  x·cos φᵢ + y·sin φᵢ
y′ = −x·sin φᵢ + y·cos φᵢ
```

팔 좌표계에서 팔꿈치와 볼조인트 쌍은

```text
E = (R + L·cos θ,  0,  −L·sin θ)
B = (x′ + r,       y′,  z)
```

### 2단계 — 로드 길이 제약을 θ에 대한 식으로

로드 길이는 l로 일정하므로 $|B − E|² = l²$. 등가 반지름 덩어리를 $a = x′ + r − R$로 두면(T03)

```text
(a − L·cos θ)² + y′² + (z + L·sin θ)² = l²
```

전개합니다.

```text
a² − 2aL·cos θ + L²cos²θ + y′² + z² + 2zL·sin θ + L²sin²θ = l²
a² + y′² + z² + L² + 2L·(z·sin θ − a·cos θ) = l²
```

θ가 들어간 항만 남기면

```text
z·sin θ − a·cos θ = K,      K = (l² − L² − a² − y′² − z²) / (2L)
```

라이브러리 `ik_arm()`의 주석과 식이 이것과 **글자 그대로** 같습니다.

### 3단계 — 사인 합성으로 풀기

$ρ = √(a² + z²)$, $α = atan2(a, z)$로 두면 $z = ρ·cos α$, $a = ρ·sin α$이므로

```text
z·sin θ − a·cos θ = ρ·(sin θ·cos α − cos θ·sin α) = ρ·sin(θ − α) = K
→  sin(θ − α) = K / ρ
```

sin 값이 같은 각은 두 개이므로 해도 두 개입니다.

```text
θ₁ = α + asin(K/ρ)
θ₂ = α + π − asin(K/ρ)
```

`asin`은 인자가 −1 ~ 1일 때만 정의되므로 **$|K| ≤ ρ$일 때만 해가 있습니다.** $|K| > ρ$이면 로드가 팔꿈치 원에 닿지 않는 것이고,
라이브러리는 `Unreachable` 예외를 던집니다.

### 4단계 — 해 고르기

두 해는 팔꿈치가 **바깥으로 꺾인 자세**와 **안쪽(베이스 중심 쪽)으로 접힌 자세**입니다. 실제 델타는 팔꿈치가 바깥을 향하도록 조립하므로
$cos θ$가 **큰** 쪽(팔꿈치의 x′ = R + L·cos θ가 더 바깥)을 고릅니다. 마지막으로 각을 (−π, π]로 감쌉니다(`atan2(sin θ, cos θ)`).

:::info 기하학적 해석 — 구 ∩ 원
팔꿈치 E는 모터축을 중심으로 반지름 L인 **원** 위에 있고(팔 평면), 볼조인트 B를 중심으로 반지름 l인 **구** 위에도 있어야 합니다.
구를 팔 평면(y′ = 0)으로 자르면 반지름 $√(l² − y′²)$인 원이 됩니다. 따라서 IK = 팔 평면 위 **두 원의 교점**입니다.
두 원이 만나지 않으면 해가 없고($|K| > ρ$), 접하면 해가 하나(작업영역 경계), 두 점에서 만나면 해가 둘입니다.
[기구학 실험실](~/tools/kinematics-lab.html)의 IK 모드가 정확히 이 그림을 보여 줍니다.
:::

@fig[t04-ik-arm-plane] 아래 예제의 팔 2를 실제 축척으로 그린 그림. 초록 점선 원(반지름 L)과 주황 점선 호(반지름 √(l² − y′²))의 두 교점이 두 해이고, cos θ가 큰 해 A(팔꿈치 바깥)를 고릅니다.

## 풀이 예제 (라이브러리로 계산)

edu_dynamixel 설계(R = 0.1, r = 0.035, L = 0.13, l = 0.3 m)에서 이펙터 중심 $P = (0.05, −0.04, −0.26)$ m의 모터각을 구합니다.
아래 코드는 유도한 식을 한 줄씩 그대로 옮겨 중간값을 모두 출력합니다.

```python run
import math
from deltarobot import DeltaDesign
from deltarobot import kinematics as kin

d = DeltaDesign.preset("edu_dynamixel")
R, r, L, l = d.R, d.r, d.L, d.l
x, y, z = 0.05, -0.04, -0.26                  # effector centre [m]

for i, phi in enumerate(kin.PHI):
    c, s = math.cos(phi), math.sin(phi)
    xp = x * c + y * s                        # arm frame
    yp = -x * s + y * c
    a = xp + r - R
    K = (l * l - L * L - a * a - yp * yp - z * z) / (2 * L)
    rho = math.hypot(a, z)
    alpha = math.atan2(a, z)
    t1 = alpha + math.asin(K / rho)
    t2 = alpha + math.pi - math.asin(K / rho)
    t = t1 if math.cos(t1) > math.cos(t2) else t2
    t = math.atan2(math.sin(t), math.cos(t))  # wrap to (-pi, pi]
    print("arm %d: x'=%+.4f y'=%+.4f a=%+.4f K=%+.4f rho=%.4f alpha=%+.4f" % (i + 1, xp, yp, a, K, rho, alpha))
    print("       t1=%+.4f (cos %+.3f)  t2=%+.4f (cos %+.3f)  -> theta=%+.6f rad (%.2f deg)"
          % (t1, math.cos(t1), t2, math.cos(t2), t, math.degrees(t)))

print("library ik:", [round(v, 6) for v in kin.ik(d, (x, y, z))])
```

```text
arm 1: x'=+0.0500 y'=-0.0400 a=-0.0150 K=+0.0141 rho=0.2604 alpha=-3.0840
       t1=-3.0297 (cos -0.994)  t2=+0.0033 (cos +1.000)  -> theta=+0.003328 rad (0.19 deg)
arm 2: x'=-0.0596 y'=-0.0233 a=-0.1246 K=-0.0407 rho=0.2883 alpha=-2.6946
       t1=-2.8362 (cos -0.954)  t2=+0.5886 (cos +0.832)  -> theta=+0.588603 rad (33.72 deg)
arm 3: x'=+0.0096 y'=+0.0633 a=-0.0554 K=-0.0060 rho=0.2658 alpha=-2.9318
       t1=-2.9545 (cos -0.983)  t2=+0.2325 (cos +0.973)  -> theta=+0.232528 rad (13.32 deg)
library ik: [0.003328, 0.588603, 0.232528]
```

손으로 따라가 보기 (팔 1, φ = 0이므로 $x′ = x$, $y′ = y$)

- $a = 0.05 + 0.035 − 0.1 = −0.015$
- $K = (0.09 − 0.0169 − 0.000225 − 0.0016 − 0.0676) / 0.26 = 0.003675 / 0.26 ≈ 0.0141$
- $ρ = √(0.015² + 0.26²) ≈ 0.2604$, $α = atan2(−0.015, −0.26) ≈ −3.0840$ (이펙터가 아래(z < 0)에 있으므로 α는 −π 근처)
- $asin(K/ρ) = asin(0.0543) ≈ 0.0543$ → $θ₁ = −3.0297$, $θ₂ = −3.0840 + π − 0.0543 ≈ 0.0033$
- cos 값이 큰 θ₂ = 0.0033 rad를 고릅니다. 팔 1은 거의 수평입니다.

관찰: 이펙터가 아래에 있으면 α가 −π 근처라서, 우리가 원하는 해는 대개 **두 번째 식**($α + π − asin$)에서 나옵니다.
"항상 θ₁ 식을 쓰면 된다"고 외우면 틀립니다. 반드시 cos 비교로 고르세요.

:::check 해석
- 팔 2의 θ = 0.589 rad(33.7°)가 가장 큽니다. 이펙터가 팔 2의 반대쪽(x′ = −0.06, 즉 팔 2에서 멀어지는 방향)에 있으므로 팔 2가 많이 내려가야 합니다.
- 버린 해(팔 2의 θ = −2.836 rad)는 위팔이 베이스 안쪽 위로 접힌 자세입니다. 모터각 한계 [−0.7, 1.5] 밖이기도 합니다.
:::

## 실습 — IK를 처음부터 구현하고 비교

```python run
import math, random
from deltarobot import DeltaDesign, DeltaRobot, WorkspaceError
from deltarobot import kinematics as kin

def my_ik(d, p):
    """Inverse kinematics from scratch: effector centre p -> (theta1, theta2, theta3)."""
    x, y, z = p
    out = []
    for i, phi in enumerate((0.0, 2 * math.pi / 3, 4 * math.pi / 3)):
        c, s = math.cos(phi), math.sin(phi)
        xp, yp = x * c + y * s, -x * s + y * c
        a = xp + d.r - d.R
        K = (d.l ** 2 - d.L ** 2 - a * a - yp * yp - z * z) / (2 * d.L)
        rho = math.hypot(a, z)
        if rho < 1e-12 or abs(K) > rho:
            raise ValueError("arm %d cannot reach %s (|K|=%.4f > rho=%.4f)" % (i + 1, p, abs(K), rho))
        alpha = math.atan2(a, z)
        cand = (alpha + math.asin(K / rho), alpha + math.pi - math.asin(K / rho))
        t = max(cand, key=math.cos)                      # elbow out
        out.append(math.atan2(math.sin(t), math.cos(t)))
    return tuple(out)

d = DeltaDesign.preset("edu_dynamixel")
random.seed(0)
worst, n = 0.0, 0
while n < 2000:
    p = (random.uniform(-0.2, 0.2), random.uniform(-0.2, 0.2), random.uniform(-0.42, -0.17))
    try:
        ref = kin.ik(d, p)
    except kin.Unreachable:
        continue
    mine = my_ik(d, p)
    worst = max(worst, max(abs(u - v) for u, v in zip(mine, ref)))
    n += 1
print("compared %d points, max |difference| = %.2e rad" % (n, worst))

# unreachable targets
far = (0.0, 0.0, -0.50)
try:
    my_ik(d, far)
except ValueError as e:
    print("my_ik     :", e)
try:
    kin.ik(d, far)
except kin.Unreachable as e:
    print("kin.ik    :", type(e).__name__, e)

# reachable by the arms, but outside the limits (robot API uses the TCP!)
robot = DeltaRobot(d)
for tcp in [(0.0, 0.0, -0.35), (0.22, 0.0, -0.37), (0.0, 0.0, -0.57)]:
    try:
        print("robot.ik%s = %s" % (tcp, [round(v, 3) for v in robot.ik(*tcp)]))
    except WorkspaceError as e:
        print("WorkspaceError:", e)
```

```text
compared 2000 points, max |difference| = 0.00e+00 rad
my_ik     : arm 1 cannot reach (0.0, 0.0, -0.5) (|K|=0.6966 > rho=0.5042)
kin.ik    : Unreachable arm 1 cannot reach (0.0000, 0.0000, -0.5000)
robot.ik(0.0, 0.0, -0.35) = [0.356, 0.356, 0.356]
WorkspaceError: 작업영역 밖: (0.220, 0.000, -0.370) m — 모터 각도 한계, 볼조인트 각도 한계
WorkspaceError: 작업영역 밖: (0.000, 0.000, -0.570) m — 팔 길이로 닿지 않음
```

읽는 법

- 직접 만든 `my_ik`와 라이브러리가 2000개 점에서 **완전히 같은** 값을 냅니다(같은 식, 같은 해 선택).
- z = −0.5 m는 너무 멀어 $|K| > ρ$ → 해가 없습니다.
- `robot.ik()`는 **TCP**를 받고, IK 해가 있어도 `limit_report()`로 모터각·볼조인트각·팔꿈치각 한계를 검사합니다.
  (0.22, 0, −0.37)은 팔은 닿지만 모터각과 볼조인트각 한계를 넘어서 거부됩니다. TCP z = −0.57은 이펙터 중심으로 −0.5이므로 앞의 `far`와 같은 점입니다.

## 자주 나는 오류와 해결

### 1) `Unreachable: arm 1 cannot reach (0.0000, 0.0000, -0.5000)`

- 원인: 목표가 팔 길이로 닿지 않는 곳입니다($|K| > ρ$). 대부분 **단위 실수**(mm를 m로 넣음, 예: z = −260)나 z 부호 실수(+0.26)입니다.
- 해결: 좌표는 m, 작업은 z < 0입니다. `kin.reachable(d, p)`로 먼저 검사하고, 도달 가능한 범위는 T07의 작업 실린더로 확인하세요.

### 2) `ValueError: math domain error`

- 원인: 직접 구현한 IK에서 `math.asin(K / rho)`에 |K/ρ| > 1이 들어갔습니다.
- 해결: `asin` 전에 `abs(K) > rho`를 검사해 의미 있는 예외를 던집니다. 궤적 계산에서 반올림 오차 때문에 1을 살짝 넘는 경우에도,
  무작정 클램프하지 말고 목표가 경계에 너무 가까운 것은 아닌지 확인하세요.

### 3) θ가 −2.8 rad처럼 이상한 값 (팔이 안으로 접힘)

- 원인: 두 해 중 항상 `alpha + asin(K/rho)`만 썼습니다. 이펙터가 아래에 있으면 α ≈ −π라서 이 식은 보통 **접힌 해**를 줍니다.
- 해결: 두 후보를 모두 계산하고 `cos`가 큰 쪽을 고릅니다. 그 뒤 `atan2(sin t, cos t)`로 (−π, π] 범위로 감쌉니다.

### 4) `WorkspaceError: 작업영역 밖: (0.220, 0.000, -0.370) m — 모터 각도 한계, 볼조인트 각도 한계`

- 원인: IK 해는 있지만 한계를 넘었습니다. `DeltaRobot`은 `move_to`·`ik` 전에 `limit_report()`로 검사합니다.
- 해결: 메시지의 이유(모터 각도 / 볼조인트 각도 / 팔꿈치 각도 / 팔 길이)를 보고 목표를 옮기거나 설계를 바꿉니다.
  `kin.limit_report(d, p)`로 각 팔의 값을 볼 수 있습니다.

### 5) 모든 모터각이 툴 길이만큼 틀림

- 원인: `kin.ik()`에 TCP를 넣었습니다(툴 길이만큼 아래의 점을 목표로 풀어 버림).
- 해결: `kin.ik(d, (x, y, z + d.tool_length))` 또는 `robot.ik(x, y, z)`를 씁니다(T03).

### 6) 팔 2·3만 틀리고 팔 1은 맞음

- 원인: 팔 좌표 회전의 부호가 틀렸습니다(`y′ = x·sin φ + y·cos φ` 등). 팔 1은 φ = 0이라 회전 실수가 드러나지 않습니다.
- 해결: `x′ = x·cos φ + y·sin φ`, `y′ = −x·sin φ + y·cos φ`. 대칭 점 (0, 0, z)에서 세 각이 같게 나오는지, 비대칭 점에서 라이브러리와 같은지 확인합니다.

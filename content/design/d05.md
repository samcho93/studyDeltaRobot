## 학습 목표

- 진공 흡착·그리퍼·전자석·펜의 **유지 원리**와 카탈로그 값(`force`, `friction`, `ferrous_only`)의 의미를 설명할 수 있습니다.
- 흡착력 $F = Δ P · A$, 그리퍼 마찰 유지력 $2μ F$를 계산하고, 궤적의 실제 가속도로 **필요 유지력 $m·|a-g|· SF$** 를 구해 툴을 판정할 수 있습니다.
- 툴 길이(TCP)와 툴 질량이 작업 높이·모터 토크에 주는 영향을 숫자로 확인할 수 있습니다.

## 툴 카탈로그

| id | 종류 | 질량 | 길이 | 유지력 (카탈로그) | 마찰계수 μ | 제약 |
|---|---|---|---|---|---|---|
| `suction_20` | 진공 흡착컵 Ø20 | 30 g | 45 mm | 18.8 N (−60 kPa 기준 이론값) | 0.5 | 평평하고 매끈한 면, 이젝터/펌프 별도 |
| `suction_40` | 진공 흡착컵 Ø40 | 50 g | 50 mm | 75.4 N (−60 kPa 기준 이론값) | 0.5 | 박스·파우치 |
| `gripper_servo` | 서보 평행 그리퍼 | 120 g | 70 mm | 파지력 15 N → 마찰로 2μF = 12 N | 0.4 | 불규칙한 모양 |
| `gripper_pneumatic` | 공압 평행 그리퍼 | 200 g | 75 mm | 파지력 60 N → 2μF = 48 N | 0.4 | 공압 라인 필요 |
| `electromagnet` | 전자석 Ø25 | 100 g | 40 mm | 100 N (밀착 시) | 0.3 | **강자성체(철)만** |
| `pen` | 펜 / 디스펜서 | 20 g | 60 mm | — | — | 집기 불가 (그리기·도포) |

모든 값은 교육용 대표값입니다. 실제 흡착컵·그리퍼는 제조사 데이터시트의 유지력 곡선과 권장 안전율을 확인하세요.

## 유지력 계산

### 진공 흡착: $F = Δ P · A$

흡착컵 안의 압력이 대기압보다 ΔP만큼 낮으면, 컵 면적 A에 걸리는 압력 차가 부품을 밀어 붙입니다.

- Ø20: $A = π (0.010)² = 3.14×10⁻⁴$ m², ΔP = 60 kPa → **F = 18.8 N**
- Ø40: $A = π (0.020)² = 1.26×10⁻³$ m², ΔP = 60 kPa → **F = 75.4 N**

카탈로그 값은 모두 **−60 kPa(게이지 압력)** 을 가정한 이론값입니다. 표면이 거칠거나 구멍이 있으면 누설로 ΔP가 줄고,
진공이 차오르는 데 시간이 걸리므로 집은 뒤 잠깐 기다려야 합니다(이 강의의 예제는 0.05~0.2 s).

### 그리퍼: $2μ F$

평행 그리퍼는 두 손가락이 파지력 F로 부품을 누르고, **마찰**로 무게를 버팁니다. 손가락이 둘이므로 마찰력은 $2μ F$입니다.
`gripper_servo`는 $2 × 0.4 × 15 = 12$ N. 모양으로 감싸 쥐는(form closure) 손가락이면 더 버티지만, 평평한 손가락은 이 값이 한계입니다.

### 전자석: 철만

전자석은 **강자성체(철)** 에만 붙습니다(`ferrous_only: true`). 플라스틱·알루미늄·스테인리스(오스테나이트계)는 붙지 않습니다.
유지력 100 N은 흡착면이 완전히 밀착했을 때 값이고, 얇은 판·도장면·틈새가 있으면 크게 줄어듭니다.

### 필요 유지력: $F_req = m·|a - g| · SF$

부품(질량 m)을 들고 가속도 **a**로 움직이면, 툴은 부품에 $m(a - g)$ (g = (0, 0, −9.81))의 힘을 줘야 합니다.
가장 나쁜 경우는 **위로 가속하면서** 중력까지 버텨야 하는 순간이며, 크기는 $m(g + a)$입니다.

$F_req = m · max |a(t) - g| · SF ≤ F_tool$

안전율 SF는 수직 방향 저속 이동이면 1.5, 고속 수평 이동(흡착컵이 옆으로 밀리며 벗겨지는 힘)이 있으면 **2 이상**을 쓰는 것이 흔한 관례입니다.

@fig[d05-holding-force] 가속도에 따른 필요 유지력 $m(g + a)· SF$ (SF = 2, 페이로드 3종)와 각 툴의 유지력(가로 점선). 선이 점선 위로 올라가면 그 툴로는 떨어뜨립니다.

:::warning 가속도 설정값 ≠ 실제 가속도
`set_speed(speed, accel)`의 `accel`은 **경로를 따라가는 방향**의 가속도 한계입니다. 아치 궤적의 둥근 모서리를 지날 때는
원심 가속도 $v²/ρ$가 더해져 훨씬 커집니다. 그래서 필요 유지력은 **기록된 동작에서 직접** 구해야 합니다(아래 실습).
시뮬레이터와 `deltarobot`은 유지력을 검사하지 않습니다 — 모자라도 부품이 떨어지지 않으니, 이 계산은 설계자의 몫입니다.
:::

## 실습 (Python) — 실제 가속도로 툴 판정

```python run
import math
from deltarobot import DeltaDesign, DeltaRobot, catalog
from deltarobot import dynamics as dyn

G = 9.81

def worst_accel(robot):
    """기록된 동작 중 |a - g| 의 최댓값 [m/s^2] (툴이 켜진 = 부품을 든 구간만)"""
    data = dyn.analyze(robot.design, robot.backend.frames)
    return max(math.sqrt(f["a"][0] ** 2 + f["a"][1] ** 2 + (f["a"][2] + G) ** 2)
               for f in data if f["tool"] == 1)

def holding_force(tool):
    t = catalog()["tools"][tool]
    if t["kind"] == "gripper":
        return 2 * t["friction"] * t["force"]      # 두 손가락 마찰 2μF
    return t["force"]                               # 흡착(−60 kPa 기준)·전자석(철만)

def pick_and_place(speed=None, accel=None):
    robot = DeltaRobot("edu_dynamixel", scene="pick_place")
    if speed:
        robot.set_speed(speed, accel)
    p = robot.parts()[0]
    b = robot.scene.bin("A")
    robot.arch_to(p["x"], p["y"], p["top"])
    robot.tool_on()
    robot.wait(0.1)
    robot.arch_to(b["x"], b["y"], robot.scene.surface_z + 0.03)
    robot.tool_off()
    return robot, worst_accel(robot)

for speed, accel in ((None, None), (0.5, 16.0)):
    robot, a = pick_and_place(speed, accel)
    print("속도 %.2f m/s, 가속도 설정 %.1f m/s^2 -> 들고 있는 동안 max|a-g| = %.1f m/s^2" % (
        robot.speed, robot.accel, a))
    for m in (0.05, 0.2, 0.5):
        need = m * a * 1.5
        ok = [t for t in catalog()["tools"] if t != "pen" and holding_force(t) >= need]
        print("  m = %.2f kg: 필요 %4.1f N (SF 1.5) -> %s" % (m, need, ", ".join(ok)))
```

```text
속도 0.25 m/s, 가속도 설정 2.5 m/s^2 -> 들고 있는 동안 max|a-g| = 12.3 m/s^2
  m = 0.05 kg: 필요  0.9 N (SF 1.5) -> suction_20, suction_40, gripper_servo, gripper_pneumatic, electromagnet
  m = 0.20 kg: 필요  3.7 N (SF 1.5) -> suction_20, suction_40, gripper_servo, gripper_pneumatic, electromagnet
  m = 0.50 kg: 필요  9.2 N (SF 1.5) -> suction_20, suction_40, gripper_servo, gripper_pneumatic, electromagnet
속도 0.50 m/s, 가속도 설정 16.0 m/s^2 -> 들고 있는 동안 max|a-g| = 23.4 m/s^2
  m = 0.05 kg: 필요  1.8 N (SF 1.5) -> suction_20, suction_40, gripper_servo, gripper_pneumatic, electromagnet
  m = 0.20 kg: 필요  7.0 N (SF 1.5) -> suction_20, suction_40, gripper_servo, gripper_pneumatic, electromagnet
  m = 0.50 kg: 필요 17.6 N (SF 1.5) -> suction_20, suction_40, gripper_pneumatic, electromagnet
```

기본 속도에서는 $|a-g|$가 12.3 m/s²로 중력보다 조금 큰 정도지만, 16 m/s²로 올리면 23.4 m/s²가 됩니다.
0.5 kg 부품이면 필요 유지력 17.6 N으로 `gripper_servo`(12 N)가 탈락하고, `suction_20`(18.8 N)은 **겨우** 통과합니다.
SF를 2로 올리면(고속 수평 이동) `suction_20`도 탈락합니다 — D09에서 같은 이유로 `suction_40`을 고릅니다.

(전자석이 목록에 있는 것은 유지력만 본 결과입니다. 부품이 철이 아니면 쓸 수 없습니다 — 다음 실습.)

## 실습 (Python) — 툴마다 집을 수 있는 부품

분류 장면(`pick_place`)의 부품 6개 중 **p1~p3은 플라스틱, p4~p6은 철(steel)** 입니다. 툴을 바꿔 각 부품 위에서 `tool_on()`을 호출해 봅니다.

```python run
from deltarobot import DeltaDesign, DeltaRobot

for tool in ("suction_20", "electromagnet", "gripper_servo"):
    d = DeltaDesign.preset("edu_dynamixel").copy(tool=tool)
    robot = DeltaRobot(d, scene="pick_place")
    got = []
    for p in robot.parts():
        z = p["top"] if d.tool_spec["kind"] != "gripper" else p["z"] + p["h"] / 2
        robot.arch_to(p["x"], p["y"], z)
        gid = robot.tool_on()
        got.append("%s(%s)%s" % (p["id"], p["material"][0], "✔" if gid else "✖"))
        if gid:
            robot.arch_to(p["x"], p["y"], z)      # 같은 자리에 도로 내려놓기
        robot.tool_off()
    print("%-14s 툴 길이 %2.0f mm, 질량 %3.0f g | %s" % (
        tool, d.tool_length * 1000, d.tool_spec["mass"] * 1000, " ".join(got)))
```

```text
suction_20     툴 길이 45 mm, 질량  30 g | p1(p)✔ p2(p)✔ p3(p)✔ p4(s)✔ p5(s)✔ p6(s)✔
electromagnet  툴 길이 40 mm, 질량 100 g | p1(p)✖ p2(p)✖ p3(p)✖ p4(s)✔ p5(s)✔ p6(s)✔
gripper_servo  툴 길이 70 mm, 질량 120 g | p1(p)✔ p2(p)✔ p3(p)✔ p4(s)✔ p5(s)✔ p6(s)✔
```

- 흡착·그리퍼는 **TCP가 부품 위 12 mm 이내**(그리퍼는 부품 바닥 ~ 윗면 + 12 mm 사이)이고 수평 거리가 가까울 때만 잡습니다. 이 조건을 벗어나면 `tool_on()`이 `None`을 돌려줍니다.
- 그리퍼는 부품 **옆면**을 쥐므로 TCP를 부품 높이의 중간까지 내렸습니다.
- 전자석은 철 부품(p4~p6)만 잡습니다.

## 툴 길이(TCP)와 툴 질량의 영향

`DeltaRobot`의 모든 좌표는 **TCP(툴 끝)** 기준입니다. TCP = 이펙터 중심 − (0, 0, 툴 길이). 툴이 길어지면 같은 로봇이라도 **TCP가 닿는 높이가 그만큼 내려갑니다.**

```python run
from deltarobot import DeltaDesign
from deltarobot import kinematics as kin
from deltarobot import dynamics as dyn

base = DeltaDesign.preset("edu_dynamixel")
print("툴               길이  이동판 질량  작업 실린더 TCP z 범위        정적 토크(중심)")
for tool in ("suction_20", "electromagnet", "gripper_servo", "gripper_pneumatic"):
    d = base.copy(tool=tool)
    c = kin.work_cylinder(d, 0.08)
    zc = (c["z_top"] + c["z_bottom"]) / 2
    tau = max(abs(t) for t in dyn.static_torques(d, (0, 0, zc)))
    print("%-17s %2.0f mm   %.3f kg    %4.0f ~ %4.0f mm (D %3.0f)   %.3f N·m" % (
        tool, d.tool_length * 1000, d.moving_plate_mass,
        (c["z_top"] - d.tool_length) * 1000, (c["z_bottom"] - d.tool_length) * 1000,
        c["diameter"] * 1000, tau))
```

```text
툴               길이  이동판 질량  작업 실린더 TCP z 범위        정적 토크(중심)
suction_20        45 mm   0.355 kg    -271 ~ -346 mm (D 339)   0.238 N·m
electromagnet     40 mm   0.424 kg    -266 ~ -341 mm (D 339)   0.273 N·m
gripper_servo     70 mm   0.445 kg    -296 ~ -371 mm (D 339)   0.283 N·m
gripper_pneumatic 75 mm   0.524 kg    -301 ~ -376 mm (D 339)   0.323 N·m
```

- **작업 실린더 지름(339 mm)은 툴과 무관**합니다. 기구학은 이펙터 중심으로 계산되고, 툴은 그 아래로 평행 이동만 시키기 때문입니다.
- **TCP 높이 범위는 툴 길이만큼 이동**합니다. 작업대 높이(= 부품 높이)를 툴에 맞춰 정해야 합니다.
- **툴 질량은 이동판 질량에 그대로 더해져** 정적 토크가 0.238 → 0.323 N·m로 36 % 늘었습니다. 가볍게 만드는 것이 곧 속도입니다.

:::design 델타에서는 툴이 길어도 각도 오차가 증폭되지 않는다
직렬 로봇은 손목 각도 오차가 툴 길이만큼 증폭되지만, 델타의 이펙터는 평행사변형 덕분에 **자세를 유지한 채 평행 이동**만 합니다.
그래서 툴이 길어도 모터 분해능에 의한 TCP 오차는 같습니다. 다만 긴 툴은 가속할 때 이펙터를 비트는 모멘트를 만들어
아래팔 로드와 볼조인트에 부담을 주고(로드 간격 w가 버팀), 제작 오차로 이펙터가 약간 기울어져 있으면 그 기울기 × 툴 길이만큼 오차가 생깁니다.
:::

## 자주 나는 오류와 해결

| 증상·메시지 | 원인 | 해결 |
|---|---|---|
| `tool_on()`이 `None` 반환 (`robot.scene.events`에 `grab_miss` 기록) | TCP가 부품 윗면에서 12 mm 넘게 떨어짐, 또는 수평으로 너무 멂 | `p["top"]`을 목표 z로, 그리퍼는 부품 높이 중간으로 |
| 전자석으로 일부 부품만 잡힘 | 전자석은 `material == "steel"`만 | 흡착·그리퍼로 바꾸거나 철 부품만 분류 |
| 펜으로 `tool_on()` 해도 아무것도 안 잡힘 | 펜은 집기 불가(그리기용) | 그리기 전용으로 사용 (D10) |
| `ValueError: 설계 오류: 알 수 없는 툴: vacuum` | 카탈로그에 없는 id | `suction_20`, `suction_40`, `gripper_servo`, `gripper_pneumatic`, `electromagnet`, `pen` 중에서 |
| 툴을 바꿨더니 `WorkspaceError: 작업영역 밖: ... — 팔 길이로 닿지 않음` | 툴 길이가 달라져 같은 TCP z가 닿지 않음 | 장면의 `surface_z`, 부품 `top`을 기준으로 목표를 다시 계산 |
| 시뮬에서는 잘 옮기는데 실물에서 떨어뜨림 | 시뮬은 유지력을 검사하지 않음 | 이 챕터의 `worst_accel()` × m × SF 로 직접 확인 |

## 과제

1. `worst_accel()`을 수평 성분과 수직 성분으로 나누고, 흡착컵에 대해 "수직: $m|a_z + g| ≤ F/SF$, 수평: $m|a_xy| ≤ μ F/SF$" 두 조건으로 다시 판정하세요. 어느 조건이 더 까다로운가요?
2. D06에서 배울 아치 모서리 반지름을 25 mm로 키우면(`arch_to(..., radius=0.025)`) `worst_accel()`이 얼마나 줄어드는지 측정하세요.
3. 전자석 부품을 흡착컵으로 옮길 때와 비교해 이동판 질량·정적 토크가 어떻게 달라지는지 표로 정리하세요.

## 학습 목표

- `robot.parts()`, `robot.bins()`로 장면 정보를 읽고, 부품 색에 맞는 상자를 고르는 자료구조를 만듭니다.
- `arch_to` → `tool_on` → `arch_to` → `tool_off`로 이루어진 pick & place 사이클을 작성합니다.
- `try/except WorkspaceError`로 닿지 않는 부품을 건너뛰는 **안전한 루프**를 만듭니다.
- `robot.scene.score()`로 결과를 채점하고, `robot.analyze()`의 `peak_ratio`, `rms_ratio`, `speed_ratio`, `curve_ratio`를 해석해 속도를 조정합니다.

## 장면 읽기

`scene="pick_place"`는 설계의 작업 실린더 크기에 맞춰 부품 6개(빨강·파랑·초록 × 플라스틱·철)와 같은 색 상자 3개를 배치합니다. 시뮬레이터 작업 탭의 **분류** 장면과 같은 숫자입니다.

```python run
from deltarobot import DeltaRobot

robot = DeltaRobot("edu_servo", scene="pick_place")
print("작업대 높이 surface_z = %.3f m" % robot.scene.data["surface_z"])
print("부품:")
for p in robot.parts():
    print("  %s %-5s %-7s x=%+.4f y=%+.4f top=%.3f size=%.3f" % (
        p["id"], p["color"], p["material"], p["x"], p["y"], p["top"], p["size"]))
print("상자:")
for b in robot.bins():
    print("  %s %-5s x=%+.4f y=%+.4f w=%.4f d=%.4f h=%.4f" % (
        b["id"], b["color"], b["x"], b["y"], b["w"], b["d"], b["h"]))
print("빨간 상자:", robot.scene.bin("A")["color"])
```

부품 dict의 키는 `id, x, y, z, top, size, h, color, material, on`입니다. `z`는 부품 **바닥**, `top`은 **윗면**(= z + h)입니다. 흡착컵은 윗면에 닿아야 하므로 집을 때는 `top`을 씁니다.

### 흡착·놓기 판정 규칙

시뮬레이터와 라이브러리는 같은 규칙으로 판정합니다(`scene.py`와 `scene.js`가 같은 코드).

- **잡기** (`tool_on`): TCP와 부품 중심의 수평 거리가 `max(12 mm, 0.45 × size)` 이하이고, 흡착·전자석은 TCP 높이가 윗면 ±12 mm 안이어야 합니다. 그리퍼는 부품 바닥에서 윗면+12 mm 사이면 됩니다. 성공하면 부품 id, 실패하면 `None`을 돌려줍니다.
- **전자석**(`electromagnet`)은 `material`이 `"steel"`인 부품만 잡습니다.
- **놓기** (`tool_off`): TCP의 x·y가 상자 사각형(`w × d`) 안이면 그 상자에 들어갑니다. 높이는 보지 않지만, 실물을 생각해 상자 턱 위에서 놓습니다.

@fig[r02-cycle] 한 사이클: 부품 윗면으로 아치 이동 → 흡착 → 상자 위로 아치 이동 → 놓기

## 예외 처리: 닿지 않는 부품 건너뛰기

실제 셀에서는 부품이 작업영역 가장자리에 놓이기도 합니다. 한 부품 때문에 전체 프로그램이 죽지 않도록 **한 사이클을 `try`로 감쌉니다.** `arch_to`는 경로 전체를 검사한 뒤에 움직이므로, 예외가 나면 로봇은 제자리에 있습니다.

```python run
from deltarobot import DeltaRobot, WorkspaceError, default_scene, DeltaDesign

scene = default_scene(DeltaDesign.preset("edu_servo"), "pick_place")
scene["parts"].append({"id": "far", "x": 0.16, "y": 0.0, "size": 0.015, "h": 0.009,
                       "color": "red", "material": "plastic"})
robot = DeltaRobot("edu_servo", scene=scene)
robot.home()
for part in robot.parts():
    if part["color"] != "red":
        continue
    try:
        robot.arch_to(part["x"], part["y"], part["top"])
        print(part["id"], "도착, 흡착:", robot.tool_on())
        robot.tool_off()
    except WorkspaceError as e:
        print(part["id"], "건너뜀 —", e)
print("현재 TCP:", [round(v, 3) for v in robot.position])
```

```text
p1 도착, 흡착: p1
p4 도착, 흡착: p4
far 건너뜀 — 작업영역 밖: (0.160, 0.000, -0.276) m — 모터 각도 한계, 볼조인트 각도 한계
현재 TCP: [-0.037, -0.034, -0.276]
```

장면은 JSON과 같은 dict라서 `default_scene()`으로 만든 뒤 부품을 더하거나 옮겨 시험 장면을 만들 수 있습니다.

:::warning except 범위는 좁게
`except Exception:`으로 모두 잡으면 `EmergencyStop`(R03 이후 비상정지)까지 삼켜서 **비상정지 후에도 루프가 계속 돕니다.** 작업영역 문제만 `WorkspaceError`로 잡고, 비상정지는 프로그램을 끝내게 두세요.
:::

## 실습: 색깔 분류 프로그램

@btn[~/tools/playground.html] Playground 열기

```python run
from deltarobot import DeltaRobot, WorkspaceError

robot = DeltaRobot("edu_servo", scene="pick_place")
surface = robot.scene.data["surface_z"]
bin_of = {b["color"]: b for b in robot.bins()}

robot.home()
for part in robot.parts():
    b = bin_of.get(part["color"])
    if b is None:
        print(part["id"], "- 맞는 상자 없음, 건너뜀")
        continue
    try:
        robot.arch_to(part["x"], part["y"], part["top"], height=0.03)
        got = robot.tool_on()
        robot.wait(0.1)
        place_z = surface + b["h"] + part["h"] + 0.005
        robot.arch_to(b["x"], b["y"], place_z, height=0.03)
        robot.tool_off()
        robot.wait(0.05)
        print("%s(%s) -> 상자 %s  [%.2f s]" % (got, part["color"], b["id"], robot.time))
    except WorkspaceError as e:
        print(part["id"], "건너뜀:", e)
robot.home()
print("점수:", robot.scene.score())
rep = robot.analyze()
print("총 %.2f s, peak %.2f, rms %.2f, speed %.2f, ok=%s" % (robot.time, rep["peak_ratio"], rep["rms_ratio"], rep["speed_ratio"], rep["ok"]))
print(rep)
```

코드 설명:

- `bin_of = {색: 상자}` 사전을 만들어 두면 부품마다 상자를 한 번에 찾습니다. 색이 같은 상자가 없으면 `get()`이 `None`을 돌려주므로 건너뜁니다.
- `place_z`는 **작업대 + 상자 높이 + 부품 높이 + 여유 5 mm**입니다. 흡착한 부품의 바닥이 상자 턱에 걸리지 않게 합니다.
- `arch_to`의 `height`는 **두 끝 중 높은 쪽**보다 얼마나 더 올라갈지입니다. 시작점과 끝점 높이가 달라도 올라가는 양이 일정합니다.
- `wait(0.1)`은 흡착이 안정될 시간입니다. 시뮬레이션에서는 없어도 잡히지만, 실물 진공 흡착은 압력이 형성될 시간이 필요합니다.
- `robot.scene.score()`는 `{"per_bin": 상자별 개수, "correct": 색이 맞은 개수, "total": 상자에 들어간 개수}`입니다.

## 모터 부하 분석: analyze()

`robot.analyze()`는 `record` 백엔드가 기록한 **모든 프레임**에서 모터 속도·가속도·토크를 계산해 모터 사양과 비교합니다(T08의 간이 동역학 모델). 비율이 1을 넘으면 문제입니다.

| 키 | 의미 | 계산 |
|---|---|---|
| `peak_ratio` | 순간 최대 토크 여유 | 최대 모터 토크 × 안전율(1.2) ÷ 피크 토크 |
| `rms_ratio` | 연속(발열) 부하 | RMS 토크 × 1.2 ÷ 정격 토크 |
| `speed_ratio` | 속도 여유 | 최대 모터 속도 ÷ 최고 속도 |
| `curve_ratio` | 속도-토크 곡선 | 그 순간 속도에서 낼 수 있는 토크 대비 필요 토크 × 1.2의 최댓값 |
| `inertia_ratio` | 부하/로터 관성비 | RC 서보처럼 감속기 내장 모터는 0 |
| `ok`, `problems` | 판정과 이유(한국어 문장) | 하나라도 1 초과면 `ok=False` |

위 결과 해석: `peak_ratio` 0.25는 피크 토크를 4분의 1만 쓴다는 뜻이고, `rms_ratio` 0.47은 **중력을 버티는 데 대부분**이 들어간 값입니다. 로봇이 가만히 있어도 위팔과 이펙터 무게를 계속 받쳐야 하기 때문입니다. `speed_ratio` 0.50은 마지막 `home()`(관절 공간 3 rad/s 이동)에서 나왔습니다.

## 속도 조정

`robot.set_speed(speed, accel)`로 직교 속도[m/s]와 가속도[m/s²]를 바꿔 같은 분류 작업을 반복해 봅니다.

```python run
from deltarobot import DeltaRobot

def run_cycle(speed, accel):
    robot = DeltaRobot("edu_servo", scene="pick_place")
    robot.set_speed(speed, accel)
    surface = robot.scene.data["surface_z"]
    bin_of = {b["color"]: b for b in robot.bins()}
    robot.home()
    for part in robot.parts():
        b = bin_of[part["color"]]
        robot.arch_to(part["x"], part["y"], part["top"])
        robot.tool_on()
        robot.wait(0.1)
        robot.arch_to(b["x"], b["y"], surface + b["h"] + part["h"] + 0.005)
        robot.tool_off()
        robot.wait(0.05)
    return robot.time, robot.scene.score()["correct"], robot.analyze()

print("speed  accel  6개시간  정답  peak  rms   speed  curve  ok")
for v, a in [(0.10, 1.0), (0.186, 1.86), (0.30, 3.0), (0.30, 6.0), (0.40, 4.0), (0.45, 6.0), (0.60, 8.0)]:
    t, ok, rep = run_cycle(v, a)
    print("%.3f  %5.2f  %6.2f s   %d   %.2f  %.2f  %.2f  %5.2f  %s" % (
        v, a, t, ok, rep["peak_ratio"], rep["rms_ratio"], rep["speed_ratio"], rep["curve_ratio"], rep["ok"]))
```

읽는 법:

- **peak·rms는 거의 안 변하는데 `curve_ratio`가 먼저 1을 넘습니다.** RC 서보는 빠르게 돌수록 낼 수 있는 토크가 줄어듭니다(속도-토크 곡선). 0.45 m/s에서는 토크 자체보다 "그 속도에서 그 토크"가 문제입니다.
- 0.6 m/s에서는 관절 속도가 서보 최고 속도(카탈로그 대표값 6 rad/s)를 넘어 **경고**가 나옵니다. `record` 백엔드라 경고만 하지만 `serial`·`ros2` 백엔드에서는 `WorkspaceError`로 **실행이 거부**됩니다. `curve_ratio`가 `inf`인 것은 최고 속도에서 낼 수 있는 토크가 0이기 때문입니다.
- 가속도만 높이면(0.3 m/s에서 3 → 6 m/s²) 시간이 12 % 줄고 `peak_ratio`는 조금 오릅니다. 짧은 이동이 많은 pick & place는 최고 속도보다 **가속도**가 사이클 시간을 좌우합니다.
- 이 설계에서 무리 없는 범위는 약 **0.3 m/s, 3~6 m/s²**입니다. R08 캡스톤에서 이 값을 씁니다.

:::info 모터 사양은 대표값
카탈로그의 MG996R 토크·속도는 교육용 대표값입니다. 같은 모델명이라도 제조사·전압에 따라 다르므로 실물에 적용할 때는 데이터시트를 확인하고, 계산 결과에 여유를 두세요.
:::

## 자주 나는 오류와 해결

### `tool_on()`이 `None`을 돌려주고 점수가 0

- **원인**: TCP가 부품 윗면 ±12 mm 밖입니다. `part["z"]`(바닥)나 `surface_z`로 내려가면 컵이 부품을 파고드는 위치라 판정 범위를 벗어납니다. 이펙터 중심 좌표(`kinematics.ik`)를 섞어 써도 툴 길이만큼 어긋납니다.
- **해결**: 집을 때는 `part["top"]`을 쓰고, `print(robot.position)`으로 도착 높이를 확인합니다.

### `KeyError: 'purple'` (색 이름으로 상자 찾기)

- **원인**: `bin_of[part["color"]]`처럼 대괄호로 찾았는데 그 색 상자가 없습니다.
- **해결**: `bin_of.get(color)`로 찾고 `None`이면 건너뜁니다. 상자 id로 찾을 때 없으면 `KeyError: "no bin 'D'"`가 납니다.

### `WorkspaceError: 경로 중간 작업영역 밖: ...`

- **원인**: 목표점은 괜찮지만 아치 경로의 **꼭대기**가 작업영역 위쪽 한계를 넘었습니다. `height`가 너무 크거나 작업영역 가장자리에서 높이 올라갈 때 납니다.
- **해결**: `height`를 줄이거나(예: 0.03 → 0.02), 가장자리 부품은 안쪽으로 먼저 이동합니다.

### `RuntimeError: analyze()는 record 백엔드에서 기록된 동작에만 쓸 수 있습니다`

- **원인**: `websim`·`serial`·`ros2` 백엔드에서 `analyze()`를 불렀습니다.
- **해결**: 분석은 Playground나 PC의 `record` 백엔드에서 먼저 하고, 검증된 속도로 실시간 백엔드를 씁니다.

### `경고: 관절 속도 ... rad/s 가 모터 한계 ... rad/s(감속 후)를 넘습니다`

- **원인**: 직교 속도가 작업영역 가장자리나 특이점 근처에서 큰 관절 속도로 바뀌었습니다.
- **해결**: `set_speed()`로 낮춥니다. 이 경고가 있는 프로그램은 실물 백엔드에서 거부됩니다.

## 과제

:::task 개인 과제
1. 철 부품만 전자석으로 옮기는 프로그램을 작성합니다. `DeltaRobot(DeltaDesign.preset("edu_servo").copy(tool="electromagnet"), scene="pick_place")`로 로봇을 만들고, 플라스틱 부품에서 `tool_on()`이 `None`을 돌려주는 것을 확인합니다.

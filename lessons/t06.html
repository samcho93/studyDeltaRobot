T06야코비안·속도·특이점

속도 관계 v = J θ̇를 유도하고 조건수로 민첩성을 평가하며, 두 종류의 특이점을 시뮬레이터에서 찾아봅니다.

선수 챕터: T05
시뮬레이터Python Playground

학습 목표#

  • 로드 길이 제약 |sᵢ|² = l²을 시간으로 미분해 속도 관계 Jx·v = diag(Jθ)·θ̇를 유도할 수 있습니다.
  • 야코비안 J = Jx⁻¹·diag(Jθ) (v = J·θ̇)와, 역행렬 없이 구하는 역속도 θ̇ᵢ = (sᵢ·v) / Jθᵢ를 코드로 계산하고 수치 미분으로 검증할 수 있습니다.
  • 조건수 κ = σmax / σmin의 의미를 설명하고 작업영역에서 민첩성(dexterity)을 평가할 수 있습니다.
  • 1형(역기구학·경계) 특이점과 2형(병렬·순기구학) 특이점을 기하학적으로 구분하고, 각각 IK·FK의 두 해가 합쳐지는 곳임을 설명할 수 있습니다.

속도 관계 유도#

팔 i의 로드 벡터를 sᵢ = Bᵢ − Eᵢ로 둡니다(볼조인트 쌍 − 팔꿈치, 베이스 좌표). 로드 길이는 일정하므로

text
sᵢ · sᵢ = l²

양변을 시간으로 미분합니다. Bᵢ = P + r·uᵢ에서 uᵢ는 상수이므로 dBᵢ/dt = v(이펙터 속도), Eᵢ는 θᵢ만의 함수이므로 dEᵢ/dt = (∂Eᵢ/∂θᵢ)·θ̇ᵢ입니다.

text
2·sᵢ · (v − (∂Eᵢ/∂θᵢ)·θ̇ᵢ) = 0
→  sᵢ · v = (sᵢ · ∂Eᵢ/∂θᵢ) · θ̇ᵢ

세 팔을 쌓으면 행렬식이 됩니다.

text
Jx · v = diag(Jθ) · θ̇

Jx = | s₁ᵀ |         Jθᵢ = sᵢ · ∂Eᵢ/∂θᵢ
     | s₂ᵀ |
     | s₃ᵀ |         ∂Eᵢ/∂θᵢ = (−L·sin θᵢ·cos φᵢ,  −L·sin θᵢ·sin φᵢ,  −L·cos θᵢ)

∂Eᵢ/∂θᵢ는 팔꿈치가 원을 따라 움직이는 방향, 즉 위팔에 수직인 팔 평면 안의 방향입니다. 라이브러리 elbow_derivative()와 같은 식입니다.

  • 순속도(FK 방향): v = J·θ̇, J = Jx⁻¹·diag(Jθ). 라이브러리 jacobian()은 inv3(jx)의 열 c에 jt[c]를 곱합니다.
  • 역속도(IK 방향): 각 행이 독립이므로 역행렬이 필요 없습니다. θ̇ᵢ = (sᵢ · v) / Jθᵢ — joint_velocity().
  • 힘–토크: 가상일 원리로 τ = Jᵀ·F (이펙터에 가할 힘 F를 내는 데 필요한 관절 토크). T08 동역학에서 씁니다.
IK가 쉬운 것처럼, 역속도도 쉽다

IK가 팔마다 독립으로 풀렸듯이 역속도도 팔마다 스칼라 나눗셈 한 번입니다. 반대로 FK가 연립 방정식이었듯이 순속도에는 3×3 역행렬 Jx⁻¹이 필요합니다. 델타(병렬로봇)에서 "역방향이 쉽고 순방향이 어렵다"는 성질은 위치·속도 모두에서 같습니다.

실습 A — 야코비안을 직접 만들고 검증#

T04 예제와 같은 점 P = (0.05, −0.04, −0.26)에서 Jx, Jθ, J를 만들고, FK를 수치 미분한 값과 비교합니다.

python시뮬 실행 가능
import math
from deltarobot import DeltaDesign
from deltarobot import kinematics as kin

d = DeltaDesign.preset("edu_dynamixel")
p = (0.05, -0.04, -0.26)
th = kin.ik(d, p)

# build Jx (rows s_i) and J_theta (s_i . dE_i/dtheta_i) exactly as in the lesson
Jx, Jt = [], []
for i in range(3):
    B = kin.ball_joint(d, i, p)
    E = kin.elbow(d, i, th[i])
    s = [B[k] - E[k] for k in range(3)]
    dE = kin.elbow_derivative(d, i, th[i])
    Jx.append(s)
    Jt.append(sum(s[k] * dE[k] for k in range(3)))
print("|s_i| =", [round(math.sqrt(sum(v * v for v in s)), 6) for s in Jx], "(= l)")
print("J_theta =", [round(v, 5) for v in Jt])

J = kin.jacobian(d, th, p)
print("J (v = J * theta_dot):")
for row in J:
    print("   [%+.4f %+.4f %+.4f]" % tuple(row))

# check against finite differences of fk
h = 1e-6
for c in range(3):
    tp = list(th); tp[c] += h
    tm = list(th); tm[c] -= h
    pp, pm = kin.fk(d, tp), kin.fk(d, tm)
    col = [(pp[k] - pm[k]) / (2 * h) for k in range(3)]
    print("column %d numeric [%+.4f %+.4f %+.4f]" % (c + 1, *col))

# inverse velocity: theta_dot_i = (s_i . v) / J_theta_i  (no matrix inverse)
v = (0.5, 0.0, 0.0)                              # 0.5 m/s along +x
qd = kin.joint_velocity(d, th, v, p)
print("theta_dot for v=(0.5,0,0):", [round(x, 4) for x in qd], "rad/s")
back = [sum(J[r][c] * qd[c] for c in range(3)) for r in range(3)]
print("J * theta_dot            :", [round(x, 6) for x in back])
print("condition number = %.3f" % kin.condition_number(d, th, p))

읽는 법

  • |sᵢ| = 0.3 = l: IK 해에서 로드 길이 제약이 정확히 만족됩니다.
  • J의 열 c는 "모터 c만 1 rad/s로 돌릴 때 이펙터 속도"입니다. 수치 미분 열과 소수점 넷째 자리까지 같습니다.
  • J의 셋째 행(z 성분)이 모두 음수입니다. 모터각이 커지면(팔이 내려가면) 이펙터가 내려간다는 부호 규약과 맞습니다.
  • +x로 0.5 m/s 움직이려면 팔 1은 올라가고(−2.14 rad/s) 팔 2·3은 내려가야 합니다. 역속도를 J에 다시 곱하면 원래 v가 나옵니다.

조건수 — 방향마다 고른가?#

J의 특이값 σ₁ ≥ σ₂ ≥ σ₃는 "모터 속도 벡터 크기 1"로 만들 수 있는 이펙터 속도 타원체의 반지름입니다. 조건수

text
κ = σmax / σmin     (1 = 모든 방향으로 똑같이 빠르고 정밀, 클수록 한 방향이 둔함)
  • κ가 크면 어떤 방향으로는 모터가 조금만 돌아도 이펙터가 크게 움직이고(분해능·오차 증폭), 다른 방향으로는 모터가 많이 돌아야 합니다(속도 한계).
  • 힘으로 보면 τ = Jᵀ·F이므로 둔한 방향으로 힘을 내려면 큰 토크가 필요합니다.
  • 라이브러리 condition_number()는 JᵀJ의 고유값(닫힌 식)에서 특이값을 구합니다. J의 세 열은 모두 m/rad 단위라서 단위 문제 없이 κ를 비교할 수 있습니다. (회전과 병진이 섞인 6자유도 로봇에서는 단위가 섞여 조건수 해석이 까다롭습니다.)

특이점#

속도 관계 Jx·v = diag(Jθ)·θ̇에서 두 행렬 중 하나가 특이(singular)해지는 곳이 특이점입니다.

1형 특이점 (역기구학 특이점, 작업영역 경계)#

  • 조건: 어떤 i에 대해 Jθᵢ = sᵢ · ∂Eᵢ/∂θᵢ = 0. 로드가 팔꿈치의 움직임 방향에 수직 → 팔 평면에서 보면 위팔과 로드(투영)가 일직선(완전히 펴지거나 접힘).
  • 의미: 역속도 θ̇ᵢ = (sᵢ·v)/Jθᵢ가 무한대. 이펙터는 sᵢ 방향으로 움직일 수 없게 되어 자유도를 잃습니다.
  • 위치: IK에서 |K| = ρ가 되어 두 해가 하나로 합쳐지는 곳, 즉 도달 가능 영역의 경계입니다. 그래서 작업영역 안쪽에는 없고 가장자리에서 다가옵니다.
  • 실무: 경계 근처는 κ가 커지므로 작업 실린더를 경계에서 여유 있게 잡고(T07), 팔꿈치 각 한계(ELBOW_MAX 165°)로 너무 펴지는 것을 막습니다.

2형 특이점 (병렬·순기구학 특이점)#

  • 조건: det Jx = 0, 즉 세 로드 벡터 s₁, s₂, s₃가 한 평면에 놓이거나 서로 평행.
  • 의미: 모터를 모두 고정해도 이펙터가 Jx의 영공간 방향으로 순간적으로 움직일 수 있습니다(자유도 증가). 강성을 잃고, 그 방향의 작은 외력도 버티려면 토크가 무한대로 필요합니다.
  • 위치: sᵢ = P − Cᵢ이므로 세 sᵢ가 한 평면 ⇔ P가 세 구 중심의 평면 위에 있음 ⇔ FK에서 h = 0(두 해가 만남). T05의 두 조립 모드가 만나는 경계입니다.
  • 델타에서는 이펙터가 팔꿈치 높이까지 올라와 로드가 수평에 가까워질 때 이 상황에 다가갑니다. 모터각 한계와 l > R − r + L 같은 치수 선택이 정상 작업영역에서 2형 특이점을 멀리 떼어 놓습니다.

실습 B — 조건수와 특이점에 다가가기#

python시뮬 실행 가능
import math, random
from deltarobot import DeltaDesign
from deltarobot import kinematics as kin

d = DeltaDesign.preset("edu_dynamixel")

print("1) along the z axis")
for z in (-0.20, -0.25, -0.30, -0.35, -0.40):
    th = kin.ik(d, (0, 0, z))
    print("   z=%.2f  theta=%.3f  kappa=%.2f" % (z, th[0], kin.condition_number(d, th)))

print("2) moving out along +x at z=-0.30 (away from arms 2 and 3)")
for x in (0.0, 0.10, 0.15, 0.20, 0.22, 0.23, 0.235):
    p = (x, 0.0, -0.30)
    try:
        th = kin.ik(d, p)
    except kin.Unreachable as e:
        print("   x=%.3f  Unreachable: %s" % (x, e))
        continue
    jx, jt = kin.jacobian_parts(d, th, p)
    ok = kin.reachable(d, p)
    print("   x=%.3f  J_theta=%s  kappa=%6.2f  elbow2=%5.1f deg  in limits=%s"
          % (x, [round(v, 4) for v in jt], kin.condition_number(d, th, p),
             math.degrees(kin.elbow_angle(d, 1, th[1], p)), ok))

print("3) type-2 check: smallest |det Jx|/l^3 over random motor angles")
random.seed(2)
best = (9.0, None)
for _ in range(20000):
    th = [random.uniform(d.theta_min, d.theta_max) for _ in range(3)]
    try:
        p = kin.fk(d, th)
    except kin.Unreachable:
        continue
    jx, jt = kin.jacobian_parts(d, th, p)
    val = abs(kin.det3(jx)) / d.l ** 3
    if val < best[0]:
        best = (val, th)
print("   min = %.3f at theta = %s" % (best[0], [round(v, 3) for v in best[1]]))

읽는 법

  1. z축 위에서는 κ가 z ≈ −0.25 m 근처에서 가장 작고(1.68), 아래로 내려갈수록 팔이 많이 내려가 κ가 커집니다(−0.40 m에서 3.54).
  2. 팔 2·3에서 멀어지는 +x 방향으로 가면 팔 2·3의 Jθ가 0.0385 → 0.0095로 줄고 κ가 15까지 치솟다가, x = 0.235에서 팔 2가 닿지 못합니다(Unreachable). 이것이 1형 특이점(경계)에 다가가는 모습입니다. 팔꿈치 각(3차원 사잇각)이 135°에 머무는 이유는 로드가 팔 평면 밖으로도 기울어 있기 때문이고, 일직선이 되는 것은 팔 평면에 투영한 로드입니다. x = 0.2부터는 이미 한계 밖(in limits=False; 팔 2·3의 |y′| = 0.866·x가 l·sin 0.6 = 0.169 m를 넘어 볼조인트 각 초과)이라 로봇 API는 가지 않습니다.
  3. 모터각 한계 안의 무작위 2만 개 자세에서 |det Jx|/l³의 최솟값은 0.181이었습니다(세 팔 모두 크게 내린 자세). 0에서 충분히 멀어, 이 설계는 한계 안에서 2형 특이점에 가까이 가지 않는다고 볼 수 있습니다(무작위 표본 기준의 근거이지 증명은 아닙니다).

시뮬레이터에서 열기

조그 탭 조건수 관찰
  1. 시뮬레이터 조그 탭에서 TCP z 슬라이더를 움직이며 표시되는 조건수가 실습 B의 1)과 같은 경향인지 봅니다. (조그 탭은 TCP 기준이므로 이펙터 중심 z = TCP z + 툴 길이입니다.)
  2. TCP를 +x 쪽으로 밀어 조건수가 커지고 볼조인트각이 빨간색(한계 초과)으로 바뀌는 지점을 기록합니다.
  3. 모터 θ1~θ3 슬라이더(순기구학)로 세 팔을 모두 크게 내려 보세요. 조건수와 이펙터 높이가 어떻게 변하나요? 이때 로드들이 이루는 모양을 관찰합니다.
  4. 같은 실험을 설계 탭에서 l을 줄인 설계로 반복하고, 조건수가 전반적으로 어떻게 달라지는지 비교합니다.

자주 나는 오류와 해결#

1) ZeroDivisionError: singular matrix#

  • 원인: kin.jacobian()이 inv3(Jx)에서 |det Jx| < 10⁻¹⁵을 만나 2형 특이점(또는 잘못된 p)으로 판단했습니다.
  • 해결: 그 자세 근처를 피하거나, 역속도만 필요하면 역행렬 없는 kin.joint_velocity()를 씁니다. kin.condition_number()는 이 경우 inf를 돌려줍니다.

2) joint_velocity() 결과가 수백 rad/s#

  • 원인: 1형 특이점 근처라 Jθᵢ ≈ 0입니다. 작업영역 경계 부근이거나 한계 밖 점을 목표로 했습니다.
  • 해결: kin.limit_report()로 목표가 한계 안인지, κ가 적당한지(예: 4 이하) 확인합니다. 궤적 계획(D06)에서 경계 근처는 속도를 낮춥니다.

3) J의 부호가 수치 미분과 반대#

  • 원인: 모터각 부호 규약(아래로 +)과 다른 ∂E/∂θ를 썼습니다. 예: E_z = +L·sin θ로 두면 z 성분의 부호가 뒤집힙니다.
  • 해결: ∂Eᵢ/∂θᵢ = (−L·sin θ·cos φ, −L·sin θ·sin φ, −L·cos θ). 이 챕터 실습 A처럼 항상 수치 미분으로 검증하세요.

4) J와 Jᵀ 혼동 (속도와 힘)#

  • 원인: 속도는 v = J·θ̇, 힘은 τ = Jᵀ·F입니다. 토크 계산에 J를 그대로 곱하면 결과가 틀립니다.
  • 해결: 라이브러리 dynamics.joint_torques()는 J[0][c]*f[0] + J[1][c]*f[1] + J[2][c]*f[2]로 열 c와 F의 내적(= Jᵀ·F)을 씁니다.

5) 조건수를 TCP 좌표로 넣음#

  • 원인: kin.condition_number(d, theta, p)의 p에 TCP를 넣었습니다. p는 이펙터 중심이어야 하며, θ와 맞지 않는 p를 주면 sᵢ 길이가 l이 아니어서 결과가 틀립니다.
  • 해결: p를 생략하면 함수가 FK로 계산합니다. 넘길 때는 kin.fk(d, theta) 값을 씁니다.

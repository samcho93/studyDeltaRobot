D03암 길이·반지름 선정

L, l, R−r 비율이 작업영역·속도·강성·토크에 주는 영향을 파라미터 스윕으로 비교합니다.

선수 챕터: T06 T07 D02
시뮬레이터Python Playground

학습 목표#

  • 치수 파라미터 R, r, L, l, w 가운데 기구학을 실제로 바꾸는 조합(R−r, l/L, 전체 크기)을 구분할 수 있습니다.
  • l/L 비와 R−r 이 작업 실린더 D×H, 속도 이득, 정적 토크, 조건수에 주는 영향을 파라미터 스윕으로 비교할 수 있습니다.
  • 요구 작업 실린더에서 출발해 치수를 정하는 절차를 따라 설계안을 만들고, 시뮬레이터에서 확인할 수 있습니다.

어떤 치수가 무엇을 바꾸나#

T03에서 정의한 다섯 치수를 다시 봅시다. 역기구학 ik_arm()을 보면 R과 r은 항상 a = x + r − R 꼴로만 등장합니다. 즉 기구학(작업영역·야코비안)은 R과 r 각각이 아니라 R − r 에만 의존합니다. 따로 의미가 있는 것은 질량·크기(모터 배치 공간, 이펙터 판 크기)입니다.

치수기구학에 주는 영향그 밖의 영향
R − r팔이 벌어진 정도. 작을수록 작업영역이 넓고 속도 이득↑, 대신 조건수↑R: 모터 3개가 들어갈 공간, r: 툴 장착 공간
L (위팔)작업영역의 크기 스케일, 속도 이득 ∝ L팔 관성 ∝ L², 중력 토크 ∝ L
l (아래팔)l/L 비로 작업영역 모양과 높이 결정로봇 전체 높이, 로드 질량·진동
w (로드 간격)기구학에는 없음 (평행사변형이라 이펙터 자세만 유지)볼조인트 각도 여유, 이펙터 회전 강성, 팔꿈치 질량

DeltaDesign.validate()는 l ≤ L 이면 "보통 l ≈ 2~2.5 L" 이라는 경고를 만듭니다. 이 범위가 왜 흔한지 숫자로 확인해 봅시다.

네 가지 비교 지표
  • 작업 실린더 D (H = 100 mm) — kinematics.work_cylinder(d, 0.10)
  • 속도 이득 — 중심에서 야코비안의 최대 특이값 σ_max [m/s per rad/s]. 모터가 1 rad/s로 돌 때 TCP가 가장 빨리 움직이는 방향의 속도. 크면 빠르지만, 같은 모터 분해능·백래시가 TCP에서 그만큼 크게 보입니다.
  • 정적 토크 — 중심에서 이동판 무게를 들고 있을 때 가장 큰 팔의 출력축 토크 (dynamics.static_torques)
  • 조건수 κ — σ_max/σ_min. 1이면 모든 방향이 같은 성능(등방성), 클수록 특정 방향이 둔해집니다. 중심과 작업 실린더 가장자리(반지름의 90 %)에서 봅니다.

파라미터 스윕#

edu_dynamixel(R = 100, r = 35, L = 130, l = 300 mm)을 기준으로 한 번에 한 가지만 바꿉니다.

python시뮬 실행 가능
import math
from deltarobot import DeltaDesign
from deltarobot import kinematics as kin
from deltarobot import dynamics as dyn

base = DeltaDesign.preset("edu_dynamixel")      # R=0.10 r=0.035 L=0.13 l=0.30
H = 0.10                                          # 요구 작업 높이 [m]

def metrics(d):
    c = kin.work_cylinder(d, H)
    rc = c["diameter"] / 2
    zc = (c["z_top"] + c["z_bottom"]) / 2
    centre = (0.0, 0.0, zc)
    th = kin.ik(d, centre)
    gain = kin.singular_values(kin.jacobian(d, th, centre))[-1]   # 최대 속도 이득 [m/s per rad/s]
    tau = max(abs(t) for t in dyn.static_torques(d, centre))       # 출력축 정적 토크 [N·m]
    k_c = kin.condition_number(d, th, centre)
    k_e = max(kin.condition_number(d, kin.ik(d, p), p)
              for p in [(0.9 * rc * math.cos(a), 0.9 * rc * math.sin(a), zc)
                        for a in (0, math.pi / 3, 2 * math.pi / 3, math.pi)])
    return c["diameter"] * 1000, zc * 1000, gain, tau, k_c, k_e

print("① l/L 스윕 (L = 130 mm 고정)")
print(" l/L  l[mm] | D[mm] z중심[mm] | 속도이득 정적토크 | 조건수 중심 가장자리")
for k in (1.5, 2.0, 2.3, 2.5, 3.0):
    d = base.copy(forearm=round(k * base.upper_arm, 4))
    D, zc, g, tau, kc, ke = metrics(d)
    print(" %.1f  %4.0f  | %5.0f  %6.0f   |  %.3f    %.3f   |  %.2f    %.2f" % (
        k, d.forearm * 1000, D, zc, g, tau, kc, ke))

print("② R−r 스윕 (r = 35, L = 130, l = 300 mm 고정)")
print(" R−r  R[mm] | D[mm] z중심[mm] | 속도이득 정적토크 | 조건수 중심 가장자리")
for dr in (0.03, 0.065, 0.1, 0.13):
    d = base.copy(base_radius=round(base.effector_radius + dr, 4))
    D, zc, g, tau, kc, ke = metrics(d)
    print(" %3.0f  %4.0f  | %5.0f  %6.0f   |  %.3f    %.3f   |  %.2f    %.2f" % (
        dr * 1000, d.base_radius * 1000, D, zc, g, tau, kc, ke))

print("③ 크기 스윕 (l/L = 2.3 유지)")
print("  L    l   | D[mm] z중심[mm] | 속도이득 정적토크 | 조건수 중심 가장자리")
for L in (0.10, 0.13, 0.16):
    d = base.copy(upper_arm=L, forearm=round(2.3 * L, 4))
    D, zc, g, tau, kc, ke = metrics(d)
    print(" %3.0f  %3.0f  | %5.0f  %6.0f   |  %.3f    %.3f   |  %.2f    %.2f" % (
        L * 1000, d.forearm * 1000, D, zc, g, tau, kc, ke))

결과 읽기#

① l/L — 작업영역은 커지지만 "공짜"가 아닙니다. 아래팔을 1.5L에서 3L로 늘리면 D는 213 → 381 mm로 커지지만, 작업 실린더의 중심이 −154 → −364 mm로 210 mm나 내려갑니다. 로봇 프레임이 그만큼 높아져야 하고, 긴 로드는 무겁고 휘기 쉽습니다. 조건수도 가장자리 기준 1.65 → 3.15로 나빠집니다. 조건수가 가장 좋은 것은 l/L = 2.0 부근(중심 1.36)이고, 2.0~2.5 구간이 "넓이 대비 높이·조건수" 균형이 맞는 구간입니다. 이것이 validate()가 말하는 "보통 l ≈ 2~2.5 L" 의 근거입니다.

② R − r — 넓이와 등방성의 교환. R − r을 30 → 130 mm로 키우면 D는 339 → 228 mm로 줄고 정적 토크는 0.267 → 0.348 N·m로 늘지만, 조건수는 2.27 → 1.03(중심)으로 거의 완벽한 등방성이 됩니다. 팔이 넓게 벌어질수록 세 팔이 이펙터를 서로 다른 방향에서 붙잡기 때문입니다. 반대로 R − r을 너무 줄이면 세 팔이 거의 평행해져 옆 방향이 둔해집니다(특이점 쪽).

③ 크기 — 비율을 유지하면 모양은 닮은꼴. L을 100 → 160 mm로 키우면(l/L = 2.3 유지) D는 178 → 415 mm로 늘고, 속도 이득(0.117 → 0.199)과 정적 토크(0.225 → 0.354 N·m)가 같이 커집니다. 같은 모터로 더 빠르지만 더 약한 로봇이 됩니다. (R, r은 고정했으므로 조건수가 조금씩 달라집니다. 완전한 닮은꼴을 원하면 R, r도 같은 비율로 키워야 합니다.)

정적 토크와 속도 이득이 항상 같이 움직이지는 않습니다

정적 토크는 중력 방향(z) 성분과 팔 자중(gravity_moment · g · cos θ)으로 정해지고, 속도 이득은 가장 빠른 방향의 값입니다. ① 에서 l/L이 커질 때 속도 이득은 커지는데 정적 토크가 약간 줄어드는 것은, 작업 높이가 내려가 위팔이 더 아래로 기울고(cos θ↓) z 방향 이득은 오히려 작아지기 때문입니다. 표 하나만 보고 결론 내리지 말고 실제 동작의 토크(D04, D06)로 다시 확인하세요.

치수 선정 절차#

  1. 요구 작업 실린더 D × H를 정한다 (D02).
  2. l/L = 2.0~2.5에서 출발한다. 로봇 높이 제약이 크면 2.0 쪽, 넓이가 중요하면 2.5 쪽.
  3. R − r을 정한다. 이펙터 판에 툴을 달 공간(r)과 모터 3개가 들어갈 공간(R)을 먼저 확보하고, 조건수(가장자리)가 너무 크면 R − r을 키운다. 이 강의에서는 가장자리 조건수 ≤ 2.5를 권장 기준으로 씁니다(업계 공통 값이 아니라 교육용 기준입니다).
  4. L로 크기를 맞춘다. D가 부족하면 비율을 유지한 채 L을 키운다. D가 넉넉하면 줄여서 관성과 토크를 아낀다.
  5. w는 볼조인트 각도(ball_joint_limit)와 이펙터가 비틀리지 않을 강성을 보고 정한다(보통 이펙터 판 크기와 비슷하게).
  6. 시뮬레이터 [설계 검증], 분석 탭의 작업영역 점구름·작업 실린더 표시로 확인한다.
D는 "원 한 바퀴 전체"가 기준

work_cylinder()는 높이마다 24방향 모두 도달 가능한 최대 반지름을 구하고, 높이 H 구간에서 그 최솟값을 지름으로 씁니다. 작업영역 점구름이 삼각형에 가까운 모양이라 어떤 방향으로는 더 멀리 가지만, 요구사항은 "어느 방향이든 되는 영역"으로 약속해야 안전합니다.

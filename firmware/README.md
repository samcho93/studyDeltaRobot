# delta_servo — 아두이노 펌웨어 (RC 서보 델타 로봇)

`delta_servo/delta_servo.ino` 는 **Arduino Uno / Nano** 로 MG996R 서보 3개와 툴 출력 1개
(진공 펌프·전자석용 릴레이/MOSFET)를 구동합니다. PC 쪽은 두 가지 중 하나로 연결합니다.

- Python 라이브러리: `DeltaRobot("edu_servo", backend="serial", port="COM3")` (`pip install pyserial`)
- ROS 2: `ros2 launch delta_robot bringup.launch.py preset:=edu_servo port:=/dev/ttyACM0`

## 1. 시리얼 프로토콜 (115200 baud, ASCII, 한 줄에 명령 하나)

| 명령 | 의미 | 응답 |
|---|---|---|
| `J d1 d2 d3` | 모터 목표각 [deg]. 0 = 위팔 수평, **+ = 아래로** | 없음 (최대 50 Hz 스트리밍) |
| `T 0` / `T 1` | 툴 끔 / 켬 | 없음 |
| `E` | **비상정지**: 서보 3개 detach(힘 풀림), 툴 끔, 이후 `J`·`T` 무시 | `ESTOP` |
| `R` | 비상정지 해제: 서보를 마지막 각도로 다시 attach | `READY` |
| `?` | 상태 조회 | `OK d1 d2 d3 tool` (현재 각도, 속도 제한 반영) |

- 잘못된 명령에는 `ERR <이유>` 를 보냅니다. 비상정지 중 `J`/`T` → `ERR estop (send R)`.
- 줄 맨 앞의 `E` 는 줄바꿈을 기다리지 않고 **즉시** 실행됩니다.
- 부팅하면 `READY delta_servo` 를 출력하고 세 팔을 20°(= `home_theta` 0.35 rad)로 보냅니다.
- Python: `robot.backend.estop()` / `robot.backend.reset()` (serial 백엔드), ROS 2: `/delta/estop` True / False.

## 2. 배선

| 신호 | 아두이노 핀 | 연결 |
|---|---|---|
| 서보 1 신호 (팔 1, +x 방향) | D9 | MG996R 주황(신호) |
| 서보 2 신호 (팔 2, 120°) | D10 | MG996R 주황 |
| 서보 3 신호 (팔 3, 240°) | D11 | MG996R 주황 |
| 툴 출력 | D7 | 로직레벨 N-MOSFET 게이트(예: IRLZ44N, 게이트 220 Ω + 10 kΩ 풀다운) 또는 릴레이 모듈 IN |
| 서보 전원 + | — | **별도 6 V, 5 A 이상** 전원(SMPS/BEC) → 서보 빨강 |
| GND | GND | 서보 전원 GND ↔ 아두이노 GND ↔ 툴 전원 GND **공통 접지** |

주의
- 서보 전원을 아두이노 5V 핀에서 끌어오지 마세요. MG996R 한 개의 정지(stall) 전류가 2.5 A 까지 올라갑니다.
  서보 전원 옆에 1000 µF 이상 전해 커패시터를 달면 전압 강하로 인한 리셋이 줄어듭니다.
- 진공 펌프·전자석은 유도성 부하입니다. 부하 양단에 **플라이백 다이오드**(1N4007/1N5819, 캐소드를 + 쪽)를
  반드시 답니다. 릴레이 모듈은 대부분 다이오드가 내장되어 있지만 부하 쪽에는 없습니다.
- active-LOW 릴레이 모듈이면 스케치의 `TOOL_ACTIVE_HIGH = false` 로 바꿉니다.
- 핀 9·10 은 Servo 라이브러리가 Timer1 을 쓰므로 `analogWrite` 용으로 쓸 수 없습니다.

## 3. 각도 → 펄스 변환

```
pulse_us = ZERO_US[i] + DIR[i] * US_PER_DEG[i] * θ_deg
```

- `ZERO_US[i]` : 위팔이 **정확히 수평(θ = 0)** 일 때의 펄스 [µs]
- `DIR[i]` : 펄스를 늘릴 때 팔이 **아래로** 가면 `+1`, 위로 가면 `-1`
- `US_PER_DEG[i]` : 1° 당 펄스 변화. MG996R 은 대략 10~11 µs/°(개체차 큼) — 직접 측정합니다.
- θ 는 `THETA_MIN = -40°` ~ `THETA_MAX = 85°` 로 잘리고(설계 기본 한계 −0.7 ~ 1.5 rad), 펄스는 600~2400 µs 로 한 번 더 잘립니다.
- 루프는 10 ms 마다 각 서보를 목표 쪽으로 최대 `MAX_SPEED_DEG_S`(기본 200°/s)만큼만 움직입니다(슬루율 제한).
  명령이 튀거나 끊겨도 팔이 갑자기 휘두르지 않습니다.

## 4. 보정 절차

1. **팔(위팔)을 빼고** 서보 혼만 단 상태로 업로드합니다. 부팅 시 서보가 20° 위치(대략 1706 µs)로 갑니다.
2. 시리얼 모니터(115200, 줄 끝 "새 줄")에서 `J 0 0 0` 을 보냅니다. 이때가 기본 `ZERO_US = 1500` 입니다.
3. 수평 **지그**(3D 프린트한 직각 블록이나 수평계)를 베이스에 대고 위팔을 혼에 조립합니다.
   스플라인 한 칸 차이는 `ZERO_US` 로 보정하면 되므로, 가능한 한 수평에 가깝게 끼웁니다.
4. 팔마다 `J` 값을 조금씩 바꿔 가며(예: `J 1.5 0 0`) 팔이 지그와 정확히 맞는 각도 a[i]를 찾습니다.
   `ZERO_US[i] += DIR[i] * US_PER_DEG[i] * a[i]` 로 고치고 다시 업로드해 `J 0 0 0` 에서 세 팔이 모두 수평인지 확인합니다.
5. `J 45 45 45` 를 보내고 각도기로 실제 각도 b 를 잽니다. `US_PER_DEG[i] *= 45 / b` 로 보정합니다.
6. `DIR` 확인: `J 10 10 10` 에서 세 팔이 모두 **아래로** 내려가야 합니다. 올라가는 팔은 `DIR = -1`.
7. 아래팔(로드)과 이펙터를 조립한 뒤 `J 20 20 20` → `J 40 40 40` 으로 천천히 움직여 보며 걸림을 확인합니다.
8. 보정값은 스케치 상단 배열에 적어 두고, 설계 JSON 에 같은 로봇임을 메모해 둡니다.

## 5. 안전 수칙

- 처음 전원을 넣을 때는 **로드를 빼고** 서보 동작부터 확인합니다. 부팅 순간 서보가 홈 각도로 튑니다.
- 작업 영역에 손을 넣기 전에 반드시 `E` 를 보내거나 서보 전원을 끕니다. 비상정지 후에는 팔이 **중력으로 떨어집니다** —
  아래에 부품·손이 없도록 하고, `R` 전에 팔을 손으로 비슷한 자세로 받쳐 둡니다.
- 서보 전원 라인에 **물리 비상정지 스위치**(전원 차단)를 따로 다는 것을 권장합니다. 소프트웨어 `E` 는 보조 수단입니다.
- 각도 한계·속도 한계를 기본값보다 넓히지 마세요. 한계를 넓히면 로드가 서로·베이스와 부딪힐 수 있습니다.
- 서보가 뜨거워지면(정지 상태에서 계속 힘을 받는 경우) 페이로드를 줄이거나 쉬는 시간을 둡니다.
- 전자석 툴은 철 부품만 잡습니다. 흡착 툴은 공기가 새는 표면(구멍·거친 면)에서 놓칠 수 있습니다.
